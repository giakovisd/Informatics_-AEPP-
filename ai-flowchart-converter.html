Αποκωδικοποιημένος Αλγόριθμος


  







  

    
    
🔑 Πώς να αποκτήσετε δωρεάν API Key

    
Η εφαρμογή αυτή λειτουργεί κατευθείαν από τον περιηγητή σας (BYOK). Αυτό σημαίνει ότι τα δεδομένα σας είναι 100% ιδιωτικά και η χρήση εντελώς δωρεάν.

    
    

      

        1
        
Google AI Studio

        
Επισκεφθείτε την επίσημη σελίδα της Google στο AI Studio και συνδεθείτε με το Google (Gmail) account σας.

      

      

        2
        
Δημιουργία Κλειδιού

        
Πατήστε το μπλε κουμπί "Create API key". Θα σας ζητηθεί να δημιουργήσετε ή να επιλέξετε ένα νέο Cloud project.

      

      

        3
        
Αντιγραφή (Copy)

        
Μόλις δημιουργηθεί το κλειδί (ένας μακρύς κωδικός με γράμματα και αριθμούς), πατήστε το κουμπί της αντιγραφής δίπλα του.

      

      

        4
        
Επικόλληση (Paste)

        
Επιστρέψτε σε αυτήν την εφαρμογή, κάντε επικόλληση το κλειδί στο πεδίο και είστε έτοιμοι! Ο browser θα το θυμάται για πάντα.

      

    


    

      💡
      
Κοστίζει κάτι; Απολύτως τίποτα! Η Google προσφέρει δωρεάν το Gemini API για εκπαιδευτική και προσωπική χρήση (με γενναιόδωρο όριο 15 αναλύσεων ανά λεπτό).
